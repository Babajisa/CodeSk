# 📌 Panduan Pengerjaan Lampiran Skripsi (TI)

Folder ini berisi template dan panduan untuk menyusun dokumen lampiran skripsi Anda. Berikut adalah daftar lampiran beserta hal-hal yang **harus Anda lakukan** untuk melengkapinya:

---

## 🛠️ Checklist Tugas Anda (Yang Harus Dikerjakan)

### [ ] Lampiran 1: Kode Program Utama
* **Tugas Anda:** 
  1. Salin seluruh isi file kode program utama Anda (terutama `app.py`).
  2. Buka dokumen Word skripsi Anda pada bagian Lampiran 1.
  3. Paste kode tersebut. Gunakan font berjenis **Courier New** atau **Consolas** ukuran **9pt** atau **10pt** dengan spasi **1.0 (single)** agar rapi dan menghemat halaman.
  4. (Opsional) Salin juga file pembuat database jika diminta (`build_db.py`).

### [ ] Lampiran 2: System Prompt / Prompt Engineering
* **Tugas Anda:**
  1. Salin teks prompt yang sudah disediakan di file [Lampiran_2_Prompt_Engineering.md](file:///d:/CodeSkripsi/lampiran/Lampiran_2_Prompt_Engineering.md) ke Word.
  2. Jelaskan secara singkat di Word bahwa prompt ini ditanamkan di sistem untuk menyaring relevansi dan membentuk kepribadian chatbot sebagai ahli tafsir.

### [ ] Lampiran 3: Rubrik Penilaian Evaluasi (Skala Likert 1-5)
* **Tugas Anda:**
  1. Salin tabel kriteria penilaian di file [Lampiran_3_Rubrik_Penilaian.md](file:///d:/CodeSkripsi/lampiran/Lampiran_3_Rubrik_Penilaian.md) ke Word.
  2. Rubrik ini penting untuk menunjukkan dasar akademis bagaimana Anda/evaluator memberikan skor uji.

### [/] Lampiran 4: Tabel Skor Mentah Pengujian
* **Tugas Anda:**
  1. Buka file [Lampiran_4_Tabel_Skor_Mentah.md](file:///d:/CodeSkripsi/lampiran/Lampiran_4_Tabel_Skor_Mentah.md).
  2. Jalankan pengujian pada chatbot Anda, ChatGPT, Gemini, dan DeepSeek menggunakan **19 kueri (pertanyaan) uji** yang sama.
  3. Nilai jawaban masing-masing model berdasarkan kriteria Likert (Skala 1-5) pada Lampiran 3.
  4. Isi skor mentah tersebut ke dalam tabel ini sebelum menghitung rata-ratanya untuk bab IV (Hasil & Pembahasan).

### [ ] Lampiran 5: Screenshot Hasil Pengujian Chatbotku (19 Gambar)
* **Tugas Anda:**
  1. Lakukan percakapan dengan chatbot Anda untuk **19 kueri pengujian**.
  2. Ambil tangkapan layar (*screenshot*) dari setiap hasil jawaban chatbot Anda. Total ada **19 tangkapan layar**.
  3. Masukkan gambar-gambar tersebut ke Word di bawah Lampiran 5. Beri label gambar seperti *Gambar L5.1*, *Gambar L5.2*, dst.

### [ ] Lampiran 6: Screenshot Hasil Pengujian ChatGPT (6 Gambar)
* **Tugas Anda:**
  1. Kirimkan **6 pertanyaan uji** pilihan ke ChatGPT (melalui web/aplikasi).
  2. Ambil screenshot jawaban dari ChatGPT (total **6 tangkapan layar**).
  3. Masukkan gambar ke Word di bawah Lampiran 6, beri label *Gambar L6.1*, dst.

### [ ] Lampiran 7: Screenshot Hasil Pengujian Gemini AI (6 Gambar)
* **Tugas Anda:**
  1. Kirimkan **6 pertanyaan uji** yang sama dengan ChatGPT ke Gemini AI.
  2. Ambil screenshot jawaban Gemini AI (total **6 tangkapan layar**).
  3. Masukkan gambar ke Word di bawah Lampiran 7, beri label *Gambar L7.1*, dst.

### [ ] Lampiran 8: Screenshot Hasil Pengujian DeepSeek AI (6 Gambar)
* **Tugas Anda:**
  1. Kirimkan **6 pertanyaan uji** yang sama ke DeepSeek AI.
  2. Ambil screenshot jawaban DeepSeek AI (total **6 tangkapan layar**).
  3. Masukkan gambar ke Word di bawah Lampiran 8, beri label *Gambar L8.1*, dst.

### [ ] Lampiran 9: Biodata Penulis
* **Tugas Anda:**
  1. Buka file [Lampiran_9_Biodata_Penulis.md](file:///d:/CodeSkripsi/lampiran/Lampiran_9_Biodata_Penulis.md).
  2. Isi informasi diri Anda (Nama, NIM, foto, riwayat pendidikan, dll.).
  3. Salin ke halaman terakhir Word skripsi Anda.

---

*💡 **Tips:** Kerjakan pengujian (Lampiran 4) terlebih dahulu agar Anda bisa sekaligus mengambil tangkapan layar untuk Lampiran 5, 6, 7, dan 8.*
